# Fridge2Fork

**Recept utifrån det du har hemma**

*[▶ Live](https://fridge2fork-one.vercel.app)*

</div>

Matsvinnet i hushåll handlar ofta om att man inte vet vad man ska laga av det som redan finns hemma. Fridge2Fork gör det enklare att hitta recept utifrån dina ingredienser — så att fler varor hinner bli middag innan de blir sopor.

Lägg till ingredienser från kylen, sök efter recept som matchar och filtrera på svårighetsgrad. Recepten sparas mellan besök och sidan har skip links samt tangentbordsvänliga kontroller.

**Stack:** HTML · CSS · JavaScript · Spoonacular API

**Case study:** [linnea.egner.se/projects/fridge2fork](https://linnea.egner.se/projects/fridge2fork)

## Kör lokalt

Statiska filer — starta en enkel server i projektmappen:

```bash
python3 -m http.server 8080
```

Öppna http://localhost:8080 och lägg API-nyckel i `assets/js/config.js`.
